# 智慧校园课程设计

本项目包含校园服务助手、校园知识问答、智能营养食堂、个人中心和管理员系统。

当前处于需求设计阶段，尚未实现业务代码。已确定后端采用 Java、前端采用 Vue；建议使用 Spring Boot 与 SQLite，具体框架版本、数据库及发行方案仍以需求文档中的确认状态为准。

## 功能范围

- 校园服务助手：多轮收集请假信息，在对话中展示表单并确认提交；查询图书及借阅、查询本人课表。
- 校园知识问答：独立对话窗口，管理员按条维护知识，保存时自动向量化，通过 RAG 检索原文并据此回答，资料不足时明确告知未查询到。
- 智能营养食堂：检查个人身体信息后推荐三个单餐套餐，选择套餐加入购物车，再确认提交简单订单。
- 个人中心：个人及身体信息、课表、请假、借还书和订单记录。
- 管理员系统：维护基础数据及审批请假；管理员预置，学生使用姓名、学号、密码注册并以学号登录。

## 运行与配置

目前没有可运行程序。目标是提供能在另一台 Windows 电脑运行的发行包，建议前端构建后由 Java 后端统一提供页面，配置和数据库文件放在程序外部。

模型密钥及其他私有配置不提交。原始需求文件包含私有配置，已从 Git 排除；公开功能要求已整理到 `docs/`。embedding 模型与聊天模型分别配置，embedding 服务尚待选定和验证。
