# 智慧校园课程设计

本项目包含校园服务助手、校园知识问答、智能营养食堂、个人中心和管理员系统。

已实现 Java 21 + Spring Boot 3.5.16 + SQLite 后端和 Vue 3 + Vite 前端，支持独立开发运行及前端打包进 JAR。主要业务和智能流程已通过自动化测试；2026-10-16 已修复完整密钥加载，并验证真实聊天与 embedding；本机私有配置已就绪，其他电脑需自行填写完整密钥。

## 功能范围

- 校园服务助手：多轮收集请假信息，在对话中展示表单并确认提交；查询图书及借阅、查询本人课表。
- 校园知识问答：独立对话窗口，管理员按条维护知识，保存时自动向量化，通过 RAG 检索原文并据此回答，资料不足时明确告知未查询到。
- 智能营养食堂：显眼的 AI 单餐推荐、供应菜品浏览与手动点餐，购物车整合在食堂中；选用 AI 套餐覆盖手动菜品，可增减份数并确认下单。
- 个人中心：个人及身体信息、课表、请假、借还书和订单记录。
- 管理员系统：维护基础数据及审批请假；管理员预置，学生使用姓名、学号、密码注册并以学号登录。

## 运行与配置

Windows 可直接双击 `code/start-campus.cmd`。首次没有 JAR 时自动安装前端依赖、构建前后端并启动；已有 JAR 时直接启动。启动成功会打开浏览器，重复点击复用已运行服务。需要 JDK 21；首次构建还需要 Maven 3.9.9 和 Node.js 22。

停止：`code\start-campus.cmd -Stop`；修改源码后重新构建：先停止，再运行 `code\start-campus.cmd -Rebuild`。脚本不修改数据库内容，私有配置仍从后端 `config/application-local.properties` 加载。

也可从仓库根目录手动执行：

```powershell
cd code/frontend
npm ci
npm run build
cd ../backend
mvn verify
java -jar target/campus-1.0.0.jar
```

访问 [本地校园系统](http://127.0.0.1:8080)。预置演示管理员 `admin` / `123456`；学生自行注册。模型未配置时仍可使用普通数据功能。

完整工具版本、模型配置、手动开发运行及测试命令见 [环境依赖清单](docs/环境依赖清单.md)，实际验证与限制见 [开发测试报告](docs/开发测试报告.md)。

模型密钥及其他私有配置不提交。原始需求文件包含私有配置，已从 Git 排除；公开功能要求已整理到 `docs/`。embedding 模型与聊天模型分别配置，本机已验证 `text-embedding-v4`，1024 维；其他电脑需按环境清单单独配置。
