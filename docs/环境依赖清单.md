## 2. 最简运行：前端打包进 Java JAR

从仓库根目录执行：

```powershell
cd code/frontend
npm ci
npm run build
cd ../backend
mvn verify
java -jar target/campus-1.0.0.jar
```

访问 [http://127.0.0.1:8080](http://127.0.0.1:8080)。Hash 路由刷新无需服务器额外重写规则。`mvn verify` 包含后端测试；前端构建必须在 Maven 打包前完成，Maven 将 `../frontend/dist` 复制到 JAR 的静态资源目录。停止旧 Java 进程后再重新打包，Windows 不能可靠覆盖正在运行的 JAR。

后端运行工作目录固定为 `code/backend`。首次启动自动创建 `data/campus.db`，启用外键、WAL、5 秒 busy timeout；Hikari 单连接串行化本地 SQLite 事务。编号迁移记录在 `schema_migrations`，再次启动不会覆盖已有用户与记录。新增结构应新增迁移，不能删除数据库假装升级。默认监听 127.0.0.1:8080，仅本机访问。

初始管理员账号 `admin`，演示密码 `123456`（2026-10-16 按用户要求简化）。可在首次建库前通过 `ADMIN_PASSWORD` 环境变量或本地 `campus.admin-password` 修改。该默认值是公开演示口令，不是真实私有凭据；修改初始化配置不重置已有管理员。学生在页面自行注册，不预置学生密码。

首次含一个演示班级、十条课程、十本书和十六道菜（含下架、零库存、同名不同作者、素食及过敏原场景），以及三个演示学生。从迁移 003 起自动录入十二条虚构知识资料，状态为“待向量化”；配置 embedding 后由管理员重建全部向量，才能用于问答。管理员正常新增/编辑仍要求向量化成功后保存。

## 3. 模型配置

在 `code/backend` 执行：

```powershell
Copy-Item config/application-local.properties.example config/application-local.properties
```

编辑这个私有文件，填入实际有效配置；启动自动读取该文件，无需激活 profile。Spring Boot 不读取 `.env`。配置文件已忽略，不要上传。

| 配置 | 含义及状态 |
| --- | --- |
| `llm.base-url` / `LLM_BASE_URL` | 默认使用需求提供的兼容接口地址 |
| `llm.model` / `LLM_MODEL` | 默认 `qwen3.8-flash`；真实调用返回 401，兼容性未能验收 |
| `llm.api-key` / `LLM_API_KEY` | 仅后端使用真实密钥，模板留空 |
| `llm.timeout-seconds` | 读取超时 30 秒，连接超时最多 10 秒；不自动重试写入 |
| `embedding.base-url` / `EMBEDDING_BASE_URL` | 独立配置，默认空；不假设聊天地址具有向量权限 |
| `embedding.model` / `EMBEDDING_MODEL` | 待选定可用服务；本次小规模 `text-embedding-v4` 探测返回 401，未将其设为默认 |
| `embedding.api-key` / `EMBEDDING_API_KEY` | 独立后端密钥 |
| `embedding.dimensions` / `EMBEDDING_DIMENSIONS` | 必须填写服务实际返回的正整数维度，默认 0 表示未配置 |
| `embedding.timeout-seconds` | 读取超时 30 秒 |
| `rag.top-k` | 默认 5，允许 1～10 |
| `rag.min-similarity` / `RAG_MIN_SIMILARITY` | 默认空；先用真实正例、无关问题、相似但缺答案问题校准到 [-1,1]，再启用问答 |

聊天和 embedding 各进行一次真实探测，需求中凭据均收到 HTTP 401；没有将凭据复制进模板或源码。需要有效权限后继续真实模型验收，不能将模拟测试的二维向量及 0.8 门槛用于真实服务。

切换 embedding 地址、模型、维度或输入规则后，在管理员“校园知识”页点击“重建全部向量”。外部调用不持有写事务；全部向量生成成功并确认资料未并发变更后一次切换，失败保留旧资料。未重建期间明确提示模型不兼容，不混算。

无密钥时注册、个人资料、管理员普通维护、请假审批、借还书及订单查询可用；智能对话与推荐提示配置不可用。知识为空时直接返回未查询到，不调用模型。不要把真实密钥放到前端 VITE 变量、命令行参数、截图或日志。

## 6. 停止、移机与常见问题

- 终端 Ctrl+C 正常停止前后端；再次运行上述命令。数据库保留，内存登录、对话、草稿、推荐、购物车和确认令牌清空。
- 停服后复制整个 `code/backend/data/` 到新电脑相同相对位置；不要只复制正在写入的 `.db`。源码下载不包含数据库；新电脑可自动建新库。
- 会话为 HttpOnly、SameSite=Strict Cookie，8 小时过期；确认令牌 15 分钟，推荐 30 分钟。单进程内存状态不支持多实例或跨重启幂等，符合当前本地课设范围。
- HTTP 401：检查对应服务地址、密钥和模型权限，错误响应不透传供应方正文。未配置与未命中是不同状态。
- 知识向量维度不符：确认模型与实际维度后重建，不手工编辑向量列。正文最长 4000 字，过长请拆成多条。
- 端口占用：停止已有进程或同步修改前后端端口和代理。数据库目录必须可写。
- `mvn`/`java`/`npm` 找不到：检查工具 PATH 和 JAVA_HOME；运行不依赖 IDE 或开发电脑的绝对路径。
- Windows 打包 JAR 重命名失败：先停止使用此 JAR 的进程，再打包。本次已复现并验证处理方式。
- 本机验证时继承的工具环境包含关闭 Node TLS 检查的变量，项目代码与说明未设置该变量；目标电脑应使用正常的证书校验配置。

## 8. Windows 一键启动（2026-10-16）

双击 `code/start-campus.cmd`，调用同目录的 `start-campus.ps1`。使用系统自带 Windows PowerShell 5.1，入口按自身位置定位项目，支持从其他工作目录启动；不写死开发机盘符或用户名。

从项目根目录也可执行：

```powershell
.\code\start-campus.cmd
.\code\start-campus.cmd -Stop
.\code\start-campus.cmd -Rebuild
```

- 默认：找到已有 JAR 就直接启动；没有 JAR 时执行 `npm ci --no-fund --no-audit`、`npm run build`、`mvn -B -DskipTests package`，随后启动打包后的前后端。首次构建需联网。自动启动不执行测试，完整测试仍使用 `mvn verify`。
- `-Rebuild`：强制重新安装前端依赖、构建前后端。正在运行时拒绝覆盖 JAR，需先 `-Stop`；已修改源码应使用此选项，默认启动不会检测源码变化。
- `-Stop`：仅停止使用本项目绝对 JAR 路径的 8080 监听进程。不会删除数据库，登录和临时购物车随服务停止清空。
- `-NoBrowser`：不打开浏览器，供命令行验证使用；可与 `-Rebuild` 组合。
- 已运行服务：核对进程为本项目 JAR 并通过 `/api/health` 后打开原服务，不重复启动。8080 被其他服务占用时拒绝启动，不终止该服务。其他方式以相对 JAR 路径启动的进程不能可靠确认归属，请在原终端停止后改用此脚本。
- Java 隐藏运行，工作目录固定 `code/backend`，最多等待 60 秒就绪。控制台关闭不会停止后台服务；使用 `-Stop` 停止。
- 日志：`code/backend/logs/campus-output.log`、`campus-error.log`，每次新启动覆盖；运行日志已被 Git 忽略。失败时控制台保留错误，超时不误报成功，保留进程供排查。
- 默认访问 `http://127.0.0.1:8080`，默认数据库 `code/backend/data/campus.db`。当前启动脚本固定 8080；不应在本地配置覆盖服务端口、监听地址或数据源后仍期待脚本沿用默认探测地址/数据路径提示。
- 工具定位：Java 优先 `JAVA_HOME`、其次 PATH；npm、Maven 使用 PATH（Maven 也接受 `MAVEN_HOME`）。兼容此前本机安装的 `%LOCALAPPDATA%/campus-build-tools/jdk-*`、`apache-maven-*`，及 `%NVM_HOME%` / `%LOCALAPPDATA%/nvm/v22.*`。脚本不自动下载工具，不携带或修改真实密钥。

| 缺失项 | 获取方式 | 校验 |
| --- | --- | --- |
| JDK 21 | Adoptium API 查询最新 Windows x64 Temurin 21 JDK，使用其官方 GitHub release ZIP | API 返回的 SHA-256 |
| Node.js/npm | Node.js 官方发行列表查询最新 22 LTS 的 Windows x64 ZIP | 同版本官方 SHASUMS256.txt |
| Maven | Maven Central 的 Apache Maven 3.9.9 ZIP | 同地址 .sha512 |

工具只解压至 `%LOCALAPPDATA%/campus-build-tools`，不调用 MSI、winget、安装器，不需要管理员权限。下载文件先校验，再检查 ZIP 路径不越界，然后验证工具版本；失败不覆盖现有安装。只清理本次 `.campus-download-*` 临时目录；已有同名但不可用的安装会报错，需人工处理，脚本不擅自删除。
